How to upload NutriVida with the camera and AI working 100% Folder structure (this is how it should look) ``` nutrivida/ ← project root folder ├── index.html ← the app (formerly nutrivida.html, renamed) ├── package.json ← identifies the project for Vercel └── api/ ← the functions that hide their key ├── analyze-photo.js └── sugestao-ia.js ``` All these folders and files go to the **same GitHub repository**. The `api/` folder is what makes Vercel understand that there are routes to Server — the name `api` is required and cannot be changed. --- Step 1 — Repository on GitHub 1. Create a new repository, e.g., `nutrivida` 2. Move the 4 items above up, maintaining this folder structure. (In the GitHub app: "Add file" → "Upload files", drag and drop everything) (once the `api` folder is included — it maintains the structure) ## Step 2 — Account at Vercel 1. Access vercel.com through your mobile browser. 2. Tap "Sign Up" → choose "Continue with GitHub" 3. Authorize Vercel to access your Ricar875 account. Step 3 — Importing the project 1. In the Vercel panel, tap "Add New" → "Project" 2. Select the `nutrivida` repository you just created. 3. You don't need to change any build settings — Vercel It automatically detects that it's a static project + functions. 4. Tap "Deploy" Step 4 — Adding your Anthropic key (the most important step) 1. Still on the Vercel panel, check out the `nutrivida` project. 2. Go to "Settings" → "Environment Variables" 3. Add: Name: `ANTHROPIC_API_KEY` - Value: your key (starts with `sk-ant-...`, you get it from console.anthropic.com → API Keys) 4. Save 5. Go to "Deployments" and tap "Redeploy" on the last deployment — This is necessary for the new variable to take effect. Step 5 — Test 1. Vercel gives you a link like `https: https://nutrivida.vercel.app 2. Open it on your phone, tap the "Photo of the Dish" tab. 3. Take the photo → tap on "Analyze dish" 4. If an error occurs, check if the variable name is correct. `ANTHROPIC_API_KEY` and if you redeployed it after saving it --- And GitHub Pages, is it still useful for anything? Yes, but not for this AI project. Simple rule for you to save: - **Simple website, without AI or backend** (customer landing pages, (static menus) → continues GitHub Pages, your usual flow - **App with AI, photo, or anything that needs to hide a key** → Vercel, the way we did it here You don't have to choose just one: you can keep both types of project. Each one on the right platform.
